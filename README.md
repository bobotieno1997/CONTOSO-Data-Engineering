### CONTOSO Data Engineering

###### This solution leverages cloud resources to efficiently source, transform, and store data within (ADLS) Gen2 for analytical processing. It was developed using Azure Synapse Analytics, with a focus on utilizing the Serverless SQL Pool and Pipelines.
